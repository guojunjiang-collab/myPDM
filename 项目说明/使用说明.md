## 一、系统概述

### 1.1 系统定位

myPDM 是一套**网页版 BOM 管理工具（PDM 系统）**，专注于产品数据全生命周期管理。系统采用前后端分离架构，通过浏览器即可使用，无需安装任何客户端软件。

### 1.2 核心功能

| 功能模块         | 说明                   |
| ------------ | -------------------- |
| **零件管理**     | 物料编码、规格、版本、状态全生命周期管理 |
| **部件管理**     | 产品结构树（BOM）管理，支持多层级展开 |
| **图文档管理**    | 图纸、技术文档及其附件的管理       |
| **BOM 管理工具** | BOM 对比、BOM 反查、图文档反查  |
| **用户看板**     | 自定义文件夹式数据看板，支持共享     |
| **库存管理**     | 库存信息管理（即将上线）         |
| **变更管理**     | ECN 工程变更管理（即将上线）     |
| **业务管理**     | 业务相关信息管理（即将上线）       |

### 1.3 技术架构

```
浏览器
  └─→ Nginx (反向代理)
       ├─ 静态页面 (React SPA)
       └─ /api/ → FastAPI 后端 → PostgreSQL + Redis
```

## 二、快速入门

### 2.1 访问系统

打开浏览器访问部署后的地址（默认 `http://localhost:8080`），进入登录页面。

### 2.2 默认账号

系统内置 4 个演示账号，对应 4 种角色权限：

| 角色       | 用户名          | 密码       | 权限范围                   |
| -------- | ------------ | -------- | ---------------------- |
| **管理员**  | `admin`      | `123456` | 全部功能，可管理用户和删除数据        |
| **工程师**  | `engineer`   | `123456` | 创建/编辑数据，可管理 BOM 和关联图文档 |
| **生产人员** | `production` | `123456` | 查看、下载、导出，不可编辑          |
| **访客**   | `guest`      | `123456` | 仅查看和预览附件               |

### 2.3 登录

1. 输入用户名和密码
2. 点击"登录"按钮
3. 登录成功后自动跳转至**仪表盘**

### 2.4 修改密码

登录后可在右上角头像/名称区域进入**系统设置 → 修改密码**进行操作（详见[系统设置](#九系统设置)章节）。

## 四、零件管理

### 4.1 功能概述

零件管理是系统的核心模块，用于管理所有物料（零件）的编码、名称、规格、版本和状态等信息。

### 4.2 零件列表

进入 `零件管理` 页面，以表格形式展示所有零件：

| 功能       | 说明                       |
| -------- | ------------------------ |
| **搜索**   | 支持按"全部字段"、"编码"或"名称"搜索    |
| **筛选**   | 按状态（草稿/冻结/发布/作废）筛选       |
| **版本显示** | 可切换"仅最新版本"或"显示所有版本"      |
| **排序**   | 点击列头可对编码、名称、版本、状态、更新时间排序 |

列表每行右侧操作按钮：

- **编辑**（✏️）：修改零件信息（需编辑权限）
- **删除**（🗑️）：删除零件（仅管理员）

其它操作

- **查看**（👁️）：打开详情弹窗（点击数据行触发弹窗）
- **升版**（⬆️）：创建新版本（当零件为发布状态时，点击编辑进入零件编辑界面，可看到升版按钮）

### 4.3 新增/编辑零件

点击"新增零件"或行内"编辑"按钮打开表单弹窗：

| 字段    | 说明                         | 必填  |
| ----- | -------------------------- | --- |
| 编码    | 唯一标识，同一编码可有多版本             | 是   |
| 名称    | 零件名称                       | 是   |
| 规格型号  | 如材质、尺寸等                    | 否   |
| 版本    | 初始为 A                      | 自动  |
| 状态    | 默认为草稿                      | 是   |
| 备注    | 附加说明                       | 否   |
| 自定义字段 | 默认为无，根据需要填写。增加自定义字段见系统设置章节 | 否   |
| 关联图文档 | 新增界面无该字段，编辑界面才可使用          | 否   |

> **权限**：管理员和工程师可新增/编辑，生产人员和访客无此权限。

### 4.4 零件详情

点击"查看"按钮打开详情弹窗，包含三个标签页：

**① 基本信息**：展示零件所有字段 + 自定义字段

**② 版本历史**：展示该零件的所有版本记录及变更说明

**③ 关联图文档**：管理该零件关联的图文档

- 点击"关联"按钮，选择要关联的图文档
- 可删除已关联的图文档
- 点击关联图文档名称可跳转查看详情

### 4.5 升版

1. 在零件列表点击"升版"按钮
2. 系统自动生成新版本（版本号递增，如 A→B→C...）
3. 新版本从原版本复制数据，状态重置为"草稿"

### 4.6 导入导出

详见[数据导入导出](#十一数据导入导出)章节。

## 五、部件管理

### 5.1 功能概述

部件（总成/装配体）管理用于定义产品结构树，一个部件可以包含多个零件或子部件，形成树形 BOM。

### 5.2 部件列表

功能与零件列表类似，支持搜索、筛选、排序等操作。

### 5.3 新增/编辑部件

与零件操作相同，字段包括：编码、名称、规格、版本、状态、备注。

### 5.4 部件详情

详情弹窗包含：

1. 基本信息+ 自定义字段

2. BOM 树：以树形结构展示该部件包含的所有子件
- 支持逐层展开/折叠
- 显示每个子件的编码、名称、规格、版本、状态
- 显示用量（数量）
3. 版本历史：同零件模块

4. 关联图文档：查看该部件关联的图文档

### 5.5 部件编辑

在部件管理->编辑，进入部件编辑界面：

1. **添加子件**：点击"添加"，弹出部件/零件选择器
   - 可搜索编码或名称
   - 选中后输入用量数量
   - 确认后子件加入 BOM 树
2. **移除子件**：点击子件行上的删除按钮
3. **编辑用量**：点击数量字段直接修改
4. **替换子件**：点击替换按钮，选择新的零件/部件

### 5.6 BOM 导出

支持两种导出方式：

- **当前部件 BOM 导出**：导出选中部件的完整 BOM 到 Excel
- **全部部件 BOM 批量导出**：将全部 BOM 数据导出到本地文件夹（需支持 File System Access API 的浏览器）

> **权限**：管理员和工程师可导出单个 BOM；仅管理员可批量导出全部 BOM。

## 六、图文档管理

### 6.1 功能概述

图文档管理用于管理图纸、技术文件等文档资料，支持附件上传、预览、下载等操作。

### 6.2 文档列表

与零件列表类似，支持搜索、筛选、排序。

### 6.3 新增/编辑图文档

| 字段   | 说明    | 必填  |
| ---- | ----- | --- |
| 文档编号 | 唯一标识  | 是   |
| 文档名称 | 文档标题  | 是   |
| 版本   | 初始为 A | 自动  |
| 状态   | 默认为草稿 | 是   |
| 备注   | 附加说明  | 否   |

### 6.4 文档详情

详情弹窗包含：

**① 基本信息** + 自定义字段

**② 附件列表**：展示该文档的所有附件

- 文件名、文件大小、上传时间
- **预览**：PDF 文件可在浏览器中直接预览
- **下载**：下载附件到本地
- **删除**：删除附件（管理员和工程师）

**③ 版本历史**：同零件模块

**④ 关联实体**：查看该文档被哪些零件/部件引用

### 6.5 上传附件

1. 在文档详情 → 附件列表，点击"上传附件"
2. 选择文件（支持 PDF、图片、Office 文档、DXF 等格式，最大 100MB）
3. 上传完成后自动显示在附件列表中

### 6.6 附件下载

- **直接下载**：浏览器直接下载附件，显示下载进度
- **流式下载**：通过 API 流式获取二进制文件

### 6.7 PDF 预览

1. 在附件列表点击"预览"按钮
2. 系统在新标签页打开 PDF 文件（浏览器原生 PDF 阅读器）
3. 支持 PDF 的翻页、缩放、搜索等原生功能
4. 非 PDF 格式会提示"该格式暂不支持预览"

### 6.8 3D 预览（STP 文件）

- 上传 STP 格式的 3D 模型文件后，系统自动在后端转换为 glTF 格式
- 通过 3D 预览端点可在浏览器中查看三维模型

## 七、BOM 管理工具

### 7.1 功能概述

管理工具页面提供跨零件/部件的 BOM 数据分析功能，包含 BOM 对比、BOM 反查、图文档反查三个子功能。

### 7.2 BOM 对比

比较两个部件（或零件与部件）的 BOM 结构差异，用于版本变更分析。

**操作步骤：**

1. 选择"类型"（左侧）：零件或部件
2. 搜索并选择左侧实体（旧版本）
3. 选择"类型"（右侧）：零件或部件
4. 搜索并选择右侧实体（新版本）
5. 点击"开始对比"

**对比结果展示：**

| 变更类型 | 颜色标识    | 说明         |
| ---- | ------- | ---------- |
| 无变更  | 默认      | 两版本数据一致    |
| 新增   | 🟢 绿色背景 | 右侧新增子件     |
| 删除   | 🔴 红色背景 | 左侧有但右侧移除   |
| 修改   | 🟡 黄色背景 | 版本、用量或规格变更 |
| 内部变更 | 🟠 橙色背景 | 子件内部结构发生变化 |

对比结果以树形表格展示，支持展开/折叠，每行标注变更类型和具体变化内容。

> **权限**：访客不可使用 BOM 对比功能。

### 7.3 BOM 反查

查询某个零件或部件被哪些上层部件所使用（Where-Used 分析）。

**操作步骤：**

1. 选择类型（零件或部件）
2. 搜索并选择要反查的实体
3. 点击"查询"
4. 系统以树形结构展示所有引用该实体的上级部件链

**示例**：反查零件 A → 可能显示：

```
部件 X (直接使用 A)
  └─ 总成 Y (X 所属的总成)
       └─ 产品 Z (Y 所属的产品)
```

> **权限**：访客不可使用 BOM 反查功能。

### 7.4 图文档反查

查询某个图文档被哪些零件、部件所引用。

**操作步骤：**

1. 搜索并选择图文档
2. 查看引用该文档的所有零件和部件列表
3. 可直接点击跳转到对应的零件/部件详情

> **权限**：访客不可使用图文档反查功能。

## 八、用户看板

### 8.1 功能概述

用户看板提供自定义文件夹式的数据管理功能，用户可以将常用的零件、部件、图文档添加到个人看板中分类管理。

### 8.2 文件夹管理

- **创建文件夹**：点击"新建文件夹"，输入名称
- **重命名**：右键/操作菜单中选择重命名
- **删除文件夹**：删除文件夹及其中所有收藏项
- **拖拽排序**：通过拖拽调整文件夹顺序

### 8.3 添加项目

1. 进入目标文件夹
2. 点击"添加项目"
3. 选择类型（零件/部件/图文档）
4. 搜索并选择要添加的实体
5. 确认后项目显示在文件夹中

文件夹内显示每个项目的编码、名称、版本和状态标签，点击可查看详情。

### 8.4 文件夹共享

将一个文件夹共享给其他用户，实现协作：

1. 点击文件夹的"共享"按钮
2. 选择要共享的用户
3. 设置权限（查看/编辑）
4. 被共享的用户在看板中会看到共享文件夹（带共享标识和来源用户信息）

### 8.5 视图筛选

看板支持按类型筛选（全部/仅零件/仅部件/仅图文档），方便快速定位特定类型的数据。

## 九、系统设置

### 9.1 功能概述

系统设置页面包含 4 个标签页：

- 修改密码
- 自定义字段
- 数据管理
- 操作日志

### 9.2 修改密码

**操作步骤：**

1. 输入当前密码
2. 输入新密码
3. 确认新密码
4. 点击"修改密码"
5. 修改成功后需重新登录

> 密码安全性由后端校验，建议使用 8 位以上包含字母和数字的密码。

### 9.3 自定义字段

自定义字段允许用户根据业务需要，为零件、部件、图文档增加额外的属性字段。

**字段类型：**

| 类型   | 说明     |
| ---- | ------ |
| 单行文本 | 短文本输入  |
| 数字   | 数值输入   |
| 下拉选择 | 单选下拉列表 |

**操作步骤：**

1. 点击"新建字段"
2. 填写字段名称（如"材料"、"表面处理"等）
3. 自动生成字段键名（field_key）
4. 选择字段类型
5. 如为下拉选择，填写选项（用换行分隔）
6. 设置是否必填
7. 选择适用实体（零件/部件/图文档，可多选）
8. 保存后，在对应实体的详情和编辑表单中会显示该字段

> **权限**：仅管理员可管理自定义字段。

### 9.4 数据管理

提供数据的全量导入/导出功能：

- **全量导出**：将所有零件、部件、图文档、BOM 数据导出到本地文件夹
- **自定义字段导出/导入**：备份或迁移自定义字段配置
- **全量导入**：从文件夹中读取 Excel 文件批量导入数据

### 9.5 操作日志

记录系统中所有用户的操作行为，支持审计追溯：

**筛选条件：**

| 条件   | 说明                 |
| ---- | ------------------ |
| 用户   | 按操作者筛选             |
| 操作类型 | 创建/更新/删除/登录        |
| 目标类型 | 零件/部件/图文档/用户/自定义字段 |
| 日期范围 | 按时间段筛选             |

日志列表显示：操作用户、操作类型、目标类型、目标 ID、操作详情、IP 地址、操作时间。

## 十、用户管理

### 10.1 功能概述

用户管理用于管理系统账号，支持创建、编辑、禁用、删除用户及重置密码。

> **权限**：仅管理员可见和操作此功能。

### 10.2 用户列表

以表格展示所有用户，包含：用户名、姓名、角色、部门、电话、状态、创建时间。

### 10.3 新增用户

1. 点击"新增用户"
2. 填写：用户名（登录用）、姓名（显示名）、角色、部门、电话
3. 设置初始密码
4. 保存后用户即可登录

### 10.4 编辑用户

可修改用户的姓名、角色、部门、电话、状态等信息。用户名创建后不可修改。

### 10.5 禁用/启用用户

- 将用户状态设为"禁用"后，该用户无法登录系统
- 设为"正常"后恢复登录权限

### 10.6 重置密码

将用户密码重置为默认密码 `123456`，用户登录后应自行修改。

### 10.7 删除用户

删除用户账号（不可恢复）。

## 十一、数据导入导出

### 11.1 概述

系统支持通过 Excel 文件批量导入导出零件、部件、图文档数据，方便数据迁移和批量维护。

### 11.2 导出操作

**方式一：Excel 导出（单个模块）**

在零件/部件/图文档列表页点击"导出"按钮，系统生成 Excel 文件下载。

- 零件导出：编码、名称、规格、版本、状态、备注
- 部件导出：编码、名称、规格、版本、状态、备注
- 图文档导出：文档编号、名称、版本、状态、备注

**方式二：文件夹导出（批量 + 附件）**

在系统设置 → 数据管理中，可将全部数据（含 BOM 结构、关联文档关系）导出到本地文件夹。每类数据一个 Excel 文件，附件一并导出。

> 文件夹导出需要浏览器支持 File System Access API（Chrome 86+ / Edge 86+）。

### 11.3 导入操作

**流程：先预览，确认后再执行。**

1. 在对应模块列表页点击"导入"
2. 选择 Excel 文件
3. 系统解析文件并显示**导入预览**：
   - 标记每行为"新增"、"更新"或"错误"
   - 显示错误原因（如编码重复、必填字段缺失等）
   - 统计关联文档匹配情况
4. 确认无误后点击"确认导入"
5. 系统批量执行导入操作

**导入注意事项：**

- Excel 文件必须包含表头行
- 编码为唯一标识，同编码已存在则执行更新
- 关联文档通过文档编号+版本匹配
- BOM 数据通过目录结构自动识别层级

> **权限**：生产人员可导出但不可导入；访客不可导入也不可导出。

## 十三、数据状态流

### 13.1 状态定义

| 状态  | 标识         | 含义                |
| --- | ---------- | ----------------- |
| 草稿  | `draft`    | 初始创建，数据正在编辑中      |
| 冻结  | `frozen`   | 数据已冻结，不可编辑（需发布审批） |
| 发布  | `released` | 正式发布，可用于生产        |
| 作废  | `obsolete` | 已废弃，不再使用          |

### 13.2 状态流转

```
草稿 ──→ 冻结 ──→ 发布 ──→ 作废
  ↑                    │
  └────── 升版 ────────┘
```

- **草稿 → 冻结**：数据完善后锁定
- **冻结 → 发布**：审核通过正式发布
- **发布 → 作废**：淘汰废弃
- **发布 → 草稿（升版）**：发布状态下点击升版，生成新版本（状态为草稿），原版本保持发布

## 十四、版本管理

### 14.1 版本号规则

系统使用 **24 进制** 版本号，字符集排除 I 和 O（避免与数字混淆）：

```
A, B, C, ... Z, AA, AB, ... AZ, BA, ... ZZ, AAA, ...
```

| 数值  | 版本号 |
| --- | --- |
| 0   | A   |
| 1   | B   |
| ... | ... |
| 23  | Z   |
| 24  | AA  |
| 25  | AB  |

### 14.2 升版操作

当需要对已发布的数据进行修订时：

1. 在列表页点击"升版"按钮
2. 输入变更说明（会记录在版本历史中）
3. 系统自动创建新版本：
   - 新版本号根据最高版本自动递增
   - 新版本复制原版本的全部数据
   - 新版本状态重置为"草稿"
   - 新版本通过 `revision_parent_id` 关联到原版本
4. 可在**版本历史**中查看完整的版本演变链

### 14.3 版本历史

在零件/部件/图文档的详情弹窗中，**版本历史**标签页展示：

- 该实体的所有版本列表
- 每个版本的版本号、状态、更新时间
- 变更说明（升版时填写的内容）
- 点击可查看具体版本的详细信息

## 十五、常见问题

### 15.1 登录问题

**Q: 忘记密码怎么办？**
联系管理员在"用户管理"中重置密码为 `123456`。

**Q: 账号被禁用了怎么办？**
联系管理员检查账号状态，如被禁用需管理员启用。

### 15.2 数据操作

**Q: 为什么我看不到新增/编辑按钮？**
您的角色权限不足。只有管理员和工程师可以编辑数据。请确认您的角色。

**Q: 为什么我无法删除数据？**
只有管理员可以删除零件、部件、图文档等主体数据。工程师只能删除关联图文档和附件。

**Q: 导入数据时提示错误怎么办？**
检查 Excel 文件格式：

- 表头名称是否与系统要求一致
- 编码是否包含非法字符
- 必填字段是否为空
- 关联文档的编号和版本是否存在

### 15.3 附件相关

**Q: 支持哪些文件格式？**
支持：JPEG、PNG、GIF、WebP、PDF、Word、Excel、DXF 等格式，最大 100MB。

**Q: 为什么我的 PDF 无法预览？**
确保新标签页没有被浏览器拦截弹窗。如被拦截，请在浏览器中允许弹出窗口。

**Q: STP 3D 文件可以预览吗？**
可以。系统后端自动将 STP 文件转换为 glTF 格式，浏览器即可查看三维模型。

### 15.4 数据同步

**Q: 页面顶部的"检出"按钮有什么用？**
"检出"按钮用于从服务器拉取最新数据并更新本地缓存。当其他用户新增或修改了数据，点击"检出"可获取最新状态。

**Q: 数据缓存有什么作用？**
系统在浏览器本地缓存了零件、部件、图文档等基础数据，便于快速加载和搜索。缓存不影响数据的实时性——每次列表刷新或操作都会从服务器获取最新数据。

### 15.5 浏览器兼容

**Q: 推荐使用什么浏览器？**
推荐使用 Chrome 86+ 或 Edge 86+ 获得最佳体验。文件夹导入导出功能需要这些浏览器支持 File System Access API。
