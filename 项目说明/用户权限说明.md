# Amo 系统用户权限说明

## 角色定义

系统共有 4 种用户角色：

| 角色 | 英文标识 | 说明 |
|------|---------|------|
| 管理员 | `admin` | 系统最高权限，可管理所有数据和用户 |
| 工程师 | `engineer` | 核心业务操作权限，可创建和编辑零件/部件/图文档 |
| 生产人员 | `production` | 只读查看业务数据，可使用用户看板 |
| 访客 | `guest` | 仅可使用用户看板功能 |

| 操作日志 | admin |

### 按钮级别控制

- **新增/编辑按钮**：仅 `admin` 和 `engineer` 可见（`Auth.canEdit()`）
- **删除按钮**：仅 `admin` 可见（部分场景 `engineer` 也可删除）
- **用户看板操作按钮**：所有角色可见

## 后端 API 权限控制

### 权限检查机制

所有需要认证的 API 通过 `require_role()` 装饰器进行权限检查：

```python
# 管理员专属
current_user: User = Depends(require_role(["admin"]))

# 管理员 + 工程师
current_user: User = Depends(require_role(["admin", "engineer"]))

# 管理员 + 工程师 + 生产人员
current_user: User = Depends(require_role(["admin", "engineer", "production"]))

# 所有角色
current_user: User = Depends(require_role(["admin", "engineer", "production", "guest"]))
```

### API 权限分布

| 权限级别 | 涵盖的 API |
|---------|-----------|
| `["admin"]` | 用户 CRUD、操作日志、删除零件/部件/图文档 |
| `["admin", "engineer"]` | 零件/部件/图文档的增删改查、BOM 管理、附件操作 |
| `["admin", "engineer", "production"]` | BOM 反查、BOM 树查询 |
| `["admin", "engineer", "production", "guest"]` | 用户看板全部操作 |

---

## 注意事项

1. **前端权限仅为 UI 控制**：隐藏按钮不等于接口保护，所有写操作必须经过后端 `require_role()` 校验
2. **production 角色目前无法查看零件/部件/图文档列表**：如需开放只读权限，需在后端对应 API 的 `require_role` 中增加 `production` 角色
3. **guest 角色仅限用户看板**：无法查看任何业务数据
4. **用户状态**：被禁用的用户（`status != "active"`）即使角色正确也无法操作
