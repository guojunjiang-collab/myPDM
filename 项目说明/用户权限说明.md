# Amo 系统用户权限说明

## 角色定义

系统共有 4 种用户角色：

| 角色   | 英文标识         | 说明                                      |
| ---- | ------------ | --------------------------------------- |
| 管理员  | `admin`      | 系统最高权限，可管理所有数据和用户                       |
| 工程师  | `engineer`   | 核心业务操作权限，可创建和编辑零件/部件/图文档/变更单/库存，可删除关联图文档和附件    |
| 生产人员 | `production` | 可查看所有业务数据，可下载/预览附件、导出 Excel/BOM，不可编辑/删除 |
| 访客   | `guest`      | 可查看数据和下载/预览附件，不可导出、编辑、删除                |

## 后端 API 权限控制

### 权限检查机制

所有需要认证的 API 通过 `require_role()` 依赖注入进行权限检查（定义于 `backend/app/routers/auth.py:44-49`）：

```python
def require_role(roles: list[str]):
    async def checker(current_user: User = Depends(get_current_active_user)):
        if current_user.role not in roles:
            raise HTTPException(status_code=403, detail="权限不足")
        return current_user
    return checker
```

认证链：`OAuth2PasswordBearer` → `get_current_user`（解码JWT+查用户） → `get_current_active_user`（检查status=="active"） → `require_role(roles)`（检查角色）

### 使用方式

```python
# 仅管理员
current_user: User = Depends(require_role(["admin"]))

# 管理员 + 工程师
current_user: User = Depends(require_role(["admin", "engineer"]))

# 管理员 + 工程师 + 生产人员
current_user: User = Depends(require_role(["admin", "engineer", "production"]))

# 所有角色
current_user: User = Depends(require_role(["admin", "engineer", "production", "guest"]))
```

## 注意事项

1. **前端权限仅为 UI 控制**：隐藏按钮不等于接口保护，所有写操作必须经过后端 `require_role()` 校验
2. **production 角色**：可查看数据、下载/预览附件、导出 Excel/BOM/PDF、管理库存单据，但不能创建/编辑/删除业务实体
3. **guest 角色**：可查看数据、下载/预览附件，不能导出、创建、编辑、删除，不能查看管理工具、BOM树、STP 3D预览
4. **engineer 角色**：可创建/编辑数据，可删除关联图文档和附件，不能删除零件/部件/图文档主体和构型/配置方案
5. **用户状态**：被禁用的用户（`status != "active"`）即使角色正确也无法操作
6. **前后端一致性**：AGENTS.md 中 `frontend-next/` 已废弃，前端权限工具函数位于 `frontend/src/stores/auth.ts`
7. **变更管理特殊性**：ECR/ECO 除了角色检查，还有创建者/审批人等业务级权限控制（创建者可编辑自己的草稿，指定审批人可审批）
8. **库存模块特殊性**：仓库/物料使用 `MASTER_ROLES`（admin, engineer），库存单据使用 `WRITE_ROLES`（admin, engineer, production），权限粒度更细
