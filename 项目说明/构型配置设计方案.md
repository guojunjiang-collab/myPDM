## 1. 功能概述

### 1.1 模块划分

构型配置模块包含两个 Tab：

| Tab | 功能 | 状态 |
|-----|------|------|
| **构型项管理** | 定义构型项、关联零部件、子构型项层级、关联图文档 | ✅ 已上线 |
| **构型配置** | 基于构型项生成配置方案，设定架次有效性 | ✅ 已上线 |

### 1.2 什么是构型配置

构型配置解决的是"**某架次飞机具体用哪些零件**"的问题。

- **构型项**定义了一个产品单元的**所有可能**组成（必选件 + 可选件）
- **构型配置**是为特定架次范围**确定**最终选用清单

### 1.3 核心能力

- **选择构型项**：通过 Modal 弹窗（ConfigItemPicker）从构型库中选取构型项，支持搜索、单选
- **自动展开清单**：根据构型项的必选/可选标记，递归生成层级配置清单到工作表
- **层级勾选**：支持构型项节点级整体勾选/取消，一键切换子树下所有零部件。乐观 UI 更新，无页面闪烁
- **更新构型项**：以最新构型项内容重建清单
- **删除关联**：解除构型项关联，允许重新选择
- **架次有效性**：指定该配置适用于哪些架次号（起始/结束范围）
- **状态管控**：草稿 → 生效 → 归档，管理员可通过单选框直接切换
- **正式配置清单**：从工作表自动同步已勾选项，支持行点击查看零件/部件/构型项详情

### 2.2 工作表与正式清单的数据流

```
┌──────────────────────────────────────────────────────────┐
│  用户操作                                                  │
│  ├─ toggle 零件/构型项节点 → 更新 working_items            │
│  ├─ 更新构型项 → 重建 working_items                        │
│  └─ 保存 → sync_working_to_formal() → 写入 profile_items  │
├──────────────────────────────────────────────────────────┤
│  API GET 返回:                                             │
│  ├─ config_tree ← 从 working_items 构建（实时编辑态）       │
│  ├─ items      ← 从 working_items 构建（配置清单表格）      │
│  └─ formal_items ← 从 profile_items 读取（正式配置清单）    │
└──────────────────────────────────────────────────────────┘
```

### 2.3 配置清单生成规则

创建/编辑配置时选择构型项 → 递归展开到**工作表**：

1. 查询 `configuration_item_parts` → 插入工作表项，`source_type='direct'`
2. 递归 `configuration_item_children` → 插入工作表项，`source_type='child'`
3. 必选件 `is_required=true` → `is_selected=true`
4. 可选件 `is_required=false` → `is_selected=false`
5. 保存时 `sync_working_to_formal()` → 将工作表中 `is_selected=true` 的项复制到正式清单

> 重新关联同一构型项会清除旧工作表并重新生成，确保数据一致性。仅当 `configuration_item_id` 实际变更时才触发重建。

## 3. 状态流转

### 3.1 状态图

```
        ┌─────────┐              ┌──────────┐              ┌───────────┐
        │  draft  │ ── 生效 ──→  │  active  │ ── 归档 ──→  │ archived  │
        │  草稿   │              │  生效中   │              │  已归档   │
        └─────────┘              └──────────┘              └───────────┘
             ↑                        │                         │
       管理员可通过单选框               │                         │
       直接切换任意状态 ←──────────────┴─────────────────────────┘
```

### 3.2 各状态含义

| 状态 | 阶段 | 说明 |
|------|------|------|
| **draft** | 编制 | 工程师正定方案，可任意修改配置清单和基本信息 |
| **active** | 执行 | 生产线以此为准，不可修改配置清单 |
| **archived** | 归档 | 飞机已交付，仅作历史追溯 |

### 3.3 各状态操作权限

| 操作 | draft | active | archived |
|------|:-----:|:------:|:--------:|
| 编辑基本信息 | ✅ | ❌ | ❌ |
| 修改配置清单 | ✅ | ❌ | ❌ |
| 删除配置 | ✅(管理员) | ✅(管理员) | ✅(管理员) |
| 查看 | ✅ | ✅ | ✅ |

## 4. 架次有效性

使用 `effectivity_start` + `effectivity_end` 表示架次范围。

| 场景 | effectivity_start | effectivity_end |
|------|-------------------|-----------------|
| 单架次 | MSN042 | MSN042 |
| 连续批次 | MSN001 | MSN050 |
| 不限范围 | 留空 | 留空 |

## 5. API 设计

### 5.1 端点总览

| 方法 | 端点 | 说明 | 权限 |
|------|------|------|------|
| `GET` | `/configurations/profiles` | 配置列表（分页、搜索、状态筛选） | 全部 |
| `POST` | `/configurations/profiles` | 创建配置 | admin, engineer |
| `GET` | `/configurations/profiles/{id}` | 详情 + 清单树 + 正式清单 | 全部 |
| `PUT` | `/configurations/profiles/{id}` | 编辑基本信息 + 同步正式清单 | admin, engineer |
| `DELETE` | `/configurations/profiles/{id}` | 删除（管理员可删任意状态） | admin |
| `PUT` | `/configurations/profiles/{id}/status` | 直接修改状态 | admin |
| `POST` | `/configurations/profiles/{id}/activate` | 生效（draft→active） | admin, engineer |
| `POST` | `/configurations/profiles/{id}/archive` | 归档（active→archived） | admin |
| `PUT` | `/configurations/profiles/{id}/items/{item_id}` | 勾选/取消单个零部件（工作表） | admin, engineer |
| `PUT` | `/configurations/profiles/{id}/config-items/{cid}/toggle` | 切换构型项节点及子树所有零部件（工作表） | admin, engineer |
| `POST` | `/configurations/profiles/{id}/regenerate` | 强制以最新构型项重建工作表 + 同步正式清单 | admin, engineer |

```json

      "is_required": true, "is_selected": true,
      "source_config_item_id": "uuid", "source_type": "direct"
    }
  ],
  "config_tree": {
    "id": "uuid", "code": "CFG-WING", "name": "机翼构型",
    "is_required": true, "is_selected": true,
    "parts": [...],
    "children": [
      {
        "id": "uuid", "code": "CFG-SUB", "name": "缝翼构型",
        "is_required": false, "is_selected": true,
        "parts": [...], "children": [...]
      }
    ]
  },

    │   │   ├── 构型项行 → 显示构型号、名称、"构型项"标签 + 勾选框
    │   │   ├── 零部件行 → 显示件号、版本、状态、名称 + 勾选框
    │   │   ├── 折叠/展开（▶/▼）
    │   │   ├── 标题栏按钮: [更新] [删除] [更换构型项] / [+ 关联构型项]
    │   │   └── 关联构型项弹窗（ConfigItemPicker Modal，模仿 DocumentPicker 风格）
    │   ├── 正式配置清单（仅选中项，默认折叠，可展开）
    │   │   └── 行点击 → 弹出详情弹窗（复用 PartDetailContent / AssemblyDetailContent / ConfigurationDetailModal）
    │   └── 乐观 UI 更新（toggle 操作即时响应，无页面闪烁/跳顶）
    └── 删除确认弹窗（管理员可见）
```

### 6.2 配置清单表格

| 层级 | 构型号 | 名称 | 类型 | 零部件件号 | 版本 | 状态 | 可选 |
|------|--------|------|------|-----------|------|------|:--:|
| 0 | CFG-001 | 机翼构型 | `构型项` | - | - | - | ☑ 必选 |
| 0 | - | 襟翼 | `零件` | PART-001 | A | 草稿 | ☑ 必选 |
| ▶ -1 | CFG-010 | 缝翼构型 | `构型项` | - | - | - | ☐ 可选 |
| -1 | - | 主缝翼 | `部件` | ASSY-020 | B | 生效 | ☑ 必选 |

- 层级编号格式与部件子项列表一致：`0` → `-1` → `--2` → `---3`
- 构型项行有子项时显示 ▶/▼ 折叠箭头
- 折叠时同时隐藏零部件和子构型项
- 可选构型项可整体勾选，联动切换整棵子树下所有零部件
- 必选构型项始终勾选，不可取消
- 零部件显示必选/可选标签
- 勾选操作使用乐观 UI：即时更新本地状态，API 后台同步，失败时回退
- 表格高度 500px，超长滚动

### 6.3 正式配置清单

- 仅显示 `is_selected=true` 或 `is_required=true` 的构型项和零部件
- 默认全部折叠，可逐层展开查看
- 表格高度 600px
- **行点击**：构型项行 → 弹出 `ConfigurationDetailModal`；零件行 → Modal 中展示 `PartDetailContent`；部件行 → Modal 中展示 `AssemblyDetailContent`
- 层级列不触发点击事件（已 `stopPropagation`）

### 6.4 乐观 UI 更新

Toggle 操作不再触发全页刷新：

| 操作 | 旧行为 | 新行为 |
|------|--------|--------|
| 勾选零件 | `await API → loadProfile()` 全量刷新 | 先 `setConfigTree(optimistic)` 即时更新 → API 后台发 → 失败则 revert |
| 勾选构型项节点 | `await API → loadProfile()` 全量刷新 | 同上，翻转整棵子树零件 → 空可选节点直接设 `is_selected` |

- 无页面闪烁
- 表格不跳回顶部
- 同级构型项互不影响（每条记录独立存储于工作表）

## 9. 设计决策

| 决策 | 理由 |
|------|------|
| 工作表/正式清单双表分离 | 工作表记录实时编辑态（含合成条目），正式清单仅在保存时同步，避免乐观更新与后端状态不一致 |
| 合成条目（item_type='config_item'） | 空可选构型项无零件可翻，需合成条目记录选中态；前端渲染时自动过滤，不显示重复行 |
| 同级隔离 | 每条工作表记录独立存储，`source_config_item_id` 精确匹配所属构型项，同级互不干扰 |
| 乐观 UI 更新 | toggle 操作即时响应，不触发全页刷新，表格不跳顶 |
| 空可选节点 `is_selected` 直接覆写 | 无零件无子节点时 `parts.some()` 永远为 false，需特殊处理保留选中态 |
| 关联构型项弹窗化 | 使用 Modal 弹窗（ConfigItemPicker）替代内联下拉，模仿 DocumentPicker 交互风格，支持搜索和单选 |
| 正式清单行点击详情 | 复用现有 PartDetailContent / AssemblyDetailContent / ConfigurationDetailModal，不新建页面 |
| 保存时才同步正式清单 | 避免每次 toggle 都触发正式表写入，减少数据库压力 |
| 构型项 ID 未变化时不重建 | 防止保存时覆盖用户手动 toggle 结果 |
| 架次用范围而非列表 | 生产批次以连续架次为主，范围可覆盖大部分场景 |
| 构型项可空 | 先建配置再关联构型项的灵活流程 |
| 管理员可删任意状态 | 生产环境中需要管理员兜底清理数据 |
