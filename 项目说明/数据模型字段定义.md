# myPDM 数据模型字段定义

> 最后更新: 2026-07-21

---

## 一、三类实体概览

| 实体 | 模型层级 | 版本控制 | 签入签出 | 自定义字段绑定层级 | entity_type |
|------|---------|---------|---------|-------------------|-------------|
| 零部件 | Master → Revision → Iteration | A→B→...→ZZ | Revision 层 | **Revision（版本）** | `component` |
| 图文档 | Master → Revision → Iteration | A→B→...→ZZ | Revision 层 | **Revision（版本）** | `document` |
| 构型项 | Master → Revision → Iteration | A→B→...→ZZ | Revision 层 | **Revision（版本）** | `configuration_item` |

---

## 二、零部件

### 2.1 part_masters（主数据）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID PK | 主键 |
| code | String(64) | 件号 |
| name | String(255) | 中文名称 |
| type | String(16) | 类型：`part`（零件）/ `assembly`（部件） |
| creator_id | UUID | 创建者 |
| created_at | DateTime | 创建时间 |
| updated_at | DateTime | 更新时间 |
| deleted_at | DateTime | 软删除（部分唯一索引 WHERE deleted_at IS NULL） |

### 2.2 part_revisions（版本）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID PK | 主键，**自定义字段 entity_id 指向此处** |
| master_id | UUID FK → part_masters.id | 所属主数据 |
| version | String(32) | 版本号：A/B/C/.../ZZ（24进制不含I/O） |
| status | String(32) | 状态：draft / frozen / released / obsolete |
| check_out_user_id | UUID, 可空 | 签出用户，NULL=未签出 |
| check_out_date | DateTime, 可空 | 签出时间 |
| latest_iteration | Integer | 最新迭代号 |
| revision_parent_id | UUID, 可空 | 升版来源 revision |
| creator_id | UUID | 创建者 |
| created_at | DateTime | 创建时间 |
| deleted_at | DateTime | 软删除 |

### 2.3 part_iterations（迭代）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID PK | 主键，**自定义字段 iteration_id 指向此处** |
| revision_id | UUID FK → part_revisions.id | 所属版本 |
| iteration | Integer | 迭代号，每次签出+1 |
| check_in_note | Text | 签入说明 |
| check_in_date | DateTime | 签入时间 |
| remark | Text | 备注 |
| document_links | JSONB | 关联图文档列表 |
| updated_at | DateTime | 更新时间 |

**自定义字段生命周期**：
- **签出**：复制上一迭代的自定义字段到新迭代（带 iteration_id）
- **撤销签出**：删除该迭代的自定义字段记录（WHERE iteration_id = ...）
- **升版**：**不复制**自定义字段到新版本

### 2.4 part_attachments（零部件附件）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID PK | 附件 ID |
| iteration_id | UUID FK → part_iterations.id | 所属迭代 |
| category | String(16) | 附件类别：`cad`（CAD附件）/ `production`（生产附件） |
| file_name | String(255) | 文件名 |
| file_size | Integer | 文件大小 |
| file_path | String(512) | 存储路径 |
| file_hash | String(128) | 文件哈希 |

### 2.5 bom_items（BOM 关系）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID PK | 主键 |
| iteration_id | UUID FK → part_iterations.id | 父部件迭代 |
| child_revision_id | UUID FK → part_revisions.id | 子零部件版本 |
| quantity | Integer | 用量 |
| unit | String(16) | 单位 |
| cad_instances | JSONB | CAD 实例矩阵列表 `[{matrix: [...], source: "catia", label: ""}]` |
| sort_order | Integer | 排序 |
| remark | Text | 备注 |
| source | String(32) | 来源：manual / catia / step |
| created_at | DateTime | 创建时间 |
| updated_at | DateTime | 更新时间 |
| deleted_at | DateTime | 软删除 |

## 三、图文档

### 3.1 document_masters（主数据）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID PK | 主键 |
| code | String(64) | 文档编号，唯一索引 |
| name | String(255) | 文档名称 |
| revisions | JSONB | 版本升版历史 `[{version, parent_version, action, user, timestamp}]` |
| creator_id | UUID | 原始创建者 |
| created_at | DateTime | 创建时间 |
| updated_at | DateTime | 更新时间 |
| deleted_at | DateTime | 软删除 |

### 3.2 document_revisions（版本）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID PK | 主键，**自定义字段 entity_id 指向此处** |
| master_id | UUID FK → document_masters.id | 所属主数据 |
| version | String(32) | 版本号：A/B/C/.../ZZ |
| status | String(32) | 状态：draft / frozen / released / obsolete |
| remark | Text | 版本备注 |
| revision_parent_id | UUID, 可空 | 升版来源 revision |
| check_out_user_id | UUID, 可空 | 签出用户 |
| check_out_date | DateTime, 可空 | 签出时间 |
| latest_iteration | Integer | 最新迭代号 |
| creator_id | UUID | 本版本创建者 |
| created_at | DateTime | 创建时间 |
| deleted_at | DateTime | 软删除 |

### 3.3 document_iterations（迭代）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID PK | 主键，**自定义字段 iteration_id 指向此处** |
| revision_id | UUID FK → document_revisions.id | 所属版本 |
| iteration | Integer | 迭代号 |
| check_in_date | DateTime | 签入时间 |
| check_in_note | Text | 签入说明 |
| created_at | DateTime | 创建时间 |

### 3.4 document_attachments（附件）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID PK | 附件 ID |
| revision_id | UUID FK → document_revisions.id | 所属版本 |
| iteration_id | UUID FK → document_iterations.id | 所属迭代 |
| file_name | String(255) | 文件名 |
| file_size | Integer | 文件大小 |
| file_path | String(512) | 存储路径 |
| file_hash | String(128) | 文件哈希 |

### 3.5 document_group_links（用户组关联，文档级权限）

| 字段 | 类型 | 说明 |
|------|------|------|
| document_id | UUID PK, FK → document_masters.id | 所属文档 Master |
| group_id | UUID PK, FK → user_groups.id | 用户组 |

**自定义字段生命周期**：
- **签出**：复制上一迭代的自定义字段到新迭代（带 iteration_id）
- **撤销签出**：删除该迭代的自定义字段记录
- **升版**：修改 entity_id 指向新的 documeent_revisions.id（复制值到新版本）

**自定义字段生命周期**：

## 五、自定义字段存储

### 5.1 custom_field_definitions（字段定义）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID PK | 主键 |
| name | String(128) | 字段显示名 |
| field_key | String(64) | 字段唯一键 |
| field_type | String(32) | 类型：text / number / select / multiselect |
| options | JSONB | 选项列表（select/multiselect 专用） |
| is_required | Boolean | 是否必填 |
| applies_to | JSONB | 适用实体类型数组：["component", "configuration_item", "document"] |
| sort_order | Integer | 排序 |

### 5.2 custom_field_values（字段值）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID PK | 主键 |
| field_id | UUID FK → definitions.id | 字段定义 |
| entity_type | String(32) | 实体类型：component / document / configuration_item |
| entity_id | UUID | 指向实体记录（revision 或 document 的 ID） |
| value_text | Text | 文本值（text/select） |
| value_number | Numeric(12,4) | 数字值（number） |
| value_json | JSONB | 多选值（multiselect） |
| iteration_id | UUID, 可空 | 迭代 ID（用于签出/撤销/删除时的快照与清理） |

### 5.3 绑定对照

| entity_type | entity_id 指向 | iteration_id 使用 |
|-------------|---------------|------------------|
| `component` | part_revisions.id | ✅ 签出复制、撤销/删除清理 |
| `document` | document_revisions.id | ✅ 签出复制、撤销/删除清理、升版迁移 |
| `configuration_item` | configuration_item_revisions.id | ✅ 签出复制、撤销清理 |

## 六、版本号序列

24进制，不含 I 和 O（易与 1 和 0 混淆）：

```
A → B → C → ... → H → J → K → ... → N → P → ... → Z
→ AA → AB → ... → AZ → BA → ... → ZZ → AAA → ...
```
