# myPDM 数据模型字段定义

> 最后更新: 2026-07-22

---

## 一、三类实体概览

| 实体 | 模型层级 | 版本控制 | 签入签出 |
|------|---------|---------|---------|
| 零部件 | Master → Revision → Iteration | A→B→...→ZZ | Revision 层 |
| 图文档 | Master → Revision → Iteration | A→B→...→ZZ | Revision 层 |
| 构型项 | Master → Revision → Iteration | A→B→...→ZZ | Revision 层 |

### 1.1 数据绑定层级总览

| 数据类型 | 零部件 | 图文档 | 构型项 | 说明 |
|---------|--------|--------|--------|------|
| **子项/子构型项** | **迭代级** `bom_items.iteration_id` | — | **迭代级** `config_item_children.parent_iteration_id` | 签出时复制到新迭代，迭代历史查看时跟随变化 |
| **附件** | **迭代级** `part_attachments.iteration_id` | **迭代级** `document_attachments.iteration_id` | — | 同上 |
| **关联零部件** | — | — | **版本级**（始终取当前迭代） | 不随迭代历史变化 |
| **关联图文档** | **版本级**（始终取当前迭代的 `document_links`） | — | **版本级**（始终取当前迭代的 `document_links`） | 不随迭代历史变化 |
| **自定义字段** | **版本级** `entity_id = revision_id` | **版本级** `entity_id = revision_id` | **版本级** `entity_id = revision_id` | 签出时内部快照 `iteration_id`，但 API 读写均按版本级 |

## 二、零部件

### 2.1 part_masters（主数据）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID PK | 主键 |
| code | String(64) | 件号 |
| name | String(255) | 中文名称 |
| type | String(16) | 类型：`part`（零件）/ `assembly`（部件） |
| creator_id | UUID | 创建者 |
| created_at | DateTime | 创建时间 |
| updated_at | DateTime | 更新时间 |
| deleted_at | DateTime | 软删除（部分唯一索引 WHERE deleted_at IS NULL） |

### 2.2 part_revisions（版本）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID PK | 主键，**自定义字段 entity_id 指向此处** |
| master_id | UUID FK → part_masters.id | 所属主数据 |
| version | String(32) | 版本号：A/B/C/.../ZZ（24进制不含I/O） |
| status | String(32) | 状态：draft / frozen / released / obsolete |
| check_out_user_id | UUID, 可空 | 签出用户，NULL=未签出 |
| check_out_date | DateTime, 可空 | 签出时间 |
| latest_iteration | Integer | 最新迭代号 |
| revision_parent_id | UUID, 可空 | 升版来源 revision |
| creator_id | UUID | 创建者 |
| created_at | DateTime | 创建时间 |
| deleted_at | DateTime | 软删除 |

### 2.3 part_iterations（迭代）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID PK | BOM 子项 `iteration_id`、附件 `iteration_id` 指向此处 |
| revision_id | UUID FK → part_revisions.id | 所属版本 |
| iteration | Integer | 迭代号，每次签出+1 |
| check_in_note | Text | 签入说明 |
| check_in_date | DateTime | 签入时间 |
| document_links | JSONB | 关联图文档列表（**版本级**，始终展示当前迭代） |
| created_at | DateTime | 创建时间 |

### 2.4 bom_items（BOM 子项关系）

> **绑定层级：迭代级**。`iteration_id` 指向父部件的迭代。签出时复制到新迭代，撤销签出时级联删除。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID PK | 主键 |
| iteration_id | UUID FK → part_iterations.id | **父部件迭代**（主绑定） |
| parent_revision_id | UUID FK → part_revisions.id | 父部件版本（冗余） |
| child_revision_id | UUID FK → part_revisions.id | 子零部件版本 |
| quantity | Integer | 用量 |
| sort_order | Integer | 排序 |
| cad_instances | JSONB | CAD 实例矩阵列表 `[{matrix: [...], source: "step", label: ""}]` |
| created_at | DateTime | 创建时间 |
| updated_at | DateTime | 更新时间 |
| deleted_at | DateTime | 软删除 |

### 2.5 part_attachments（零部件附件）

> **绑定层级：迭代级**。`iteration_id` 指向所属迭代。签出时复制，撤销签出时级联删除。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID PK | 附件 ID |
| iteration_id | UUID FK → part_iterations.id | **所属迭代** |
| category | String(16) | 附件类别：`cad`（CAD附件）/ `production`（生产附件） |
| file_name | String(255) | 文件名 |
| file_size | Integer | 文件大小 |
| file_path | String(512) | 存储路径 |
| file_hash | String(128) | 文件哈希 |

### 2.6 关联图文档

> **绑定层级：版本级**。存储在 `part_iterations.document_links` JSONB 列，签出时复制到新迭代。前端始终展示当前最新迭代的图文档，不随迭代历史变化。

### 2.7 自定义字段

> **绑定层级：版本级**。`entity_id = part_revisions.id`。内部支持迭代快照（`iteration_id` 列），签出时复制，撤销签出时清理，但 API 读写按版本级操作，不区分迭代。

**自定义字段生命周期**：
- **签出**：复制上一迭代的自定义字段到新迭代（带 iteration_id 快照）
- **撤销签出**：删除该迭代的自定义字段记录（WHERE iteration_id = ...）
- **升版**：**不复制**自定义字段到新版本

## 三、图文档

### 3.1 document_masters（主数据）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID PK | 主键 |
| code | String(64) | 文档编号，唯一索引 |
| name | String(255) | 文档名称 |
| revisions | JSONB | 版本升版历史 `[{version, parent_version, action, user, timestamp}]` |
| creator_id | UUID | 原始创建者 |
| created_at | DateTime | 创建时间 |
| updated_at | DateTime | 更新时间 |
| deleted_at | DateTime | 软删除 |

### 3.2 document_revisions（版本）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID PK | 主键，**自定义字段 entity_id 指向此处** |
| master_id | UUID FK → document_masters.id | 所属主数据 |
| version | String(32) | 版本号：A/B/C/.../ZZ |
| status | String(32) | 状态：draft / frozen / released / obsolete |
| remark | Text | 版本备注 |
| revision_parent_id | UUID, 可空 | 升版来源 revision |
| check_out_user_id | UUID, 可空 | 签出用户 |
| check_out_date | DateTime, 可空 | 签出时间 |
| latest_iteration | Integer | 最新迭代号 |
| creator_id | UUID | 本版本创建者 |
| created_at | DateTime | 创建时间 |
| deleted_at | DateTime | 软删除 |

### 3.3 document_iterations（迭代）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID PK | **附件 iteration_id 指向此处** |
| revision_id | UUID FK → document_revisions.id | 所属版本 |
| iteration | Integer | 迭代号 |
| check_in_date | DateTime | 签入时间 |
| check_in_note | Text | 签入说明 |
| created_at | DateTime | 创建时间 |

### 3.4 document_attachments（附件）

> **绑定层级：迭代级**。`iteration_id` 指向所属迭代。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID PK | 附件 ID |
| revision_id | UUID FK → document_revisions.id | 所属版本（冗余） |
| iteration_id | UUID FK → document_iterations.id | **所属迭代** |
| file_name | String(255) | 文件名 |
| file_size | Integer | 文件大小 |
| file_path | String(512) | 存储路径 |
| file_hash | String(128) | 文件哈希 |

### 3.5 document_group_links（用户组关联，文档级权限）

| 字段 | 类型 | 说明 |
|------|------|------|
| document_id | UUID PK, FK → document_masters.id | 所属文档 Master |
| group_id | UUID PK, FK → user_groups.id | 用户组 |

### 3.6 自定义字段

> **绑定层级：版本级**。`entity_id = document_revisions.id`。内部支持迭代快照（`iteration_id` 列）。

**自定义字段生命周期**：
- **签出**：复制上一迭代的自定义字段到新迭代（带 iteration_id 快照）
- **撤销签出**：删除该迭代的自定义字段记录
- **升版**：修改 entity_id 指向新的 document_revisions.id（复制值到新版本）

## 四、构型项

### 4.1 configuration_item_masters（主数据）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID PK | 主键 |
| code | String(64) | 构型号 |
| name | String(255) | 名称 |
| creator_id | UUID | 创建者 |
| created_at | DateTime | 创建时间 |
| updated_at | DateTime | 更新时间 |
| deleted_at | DateTime | 软删除 |

### 4.2 configuration_item_revisions（版本）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID PK | 主键，**自定义字段 entity_id 指向此处** |
| master_id | UUID FK → masters.id | 所属主数据 |
| version | String(8) | 版本号：A/B/C/.../ZZ |
| status | String(32) | 状态：draft / frozen / released / obsolete |
| check_out_user_id | UUID, 可空 | 签出用户 |
| check_out_date | DateTime, 可空 | 签出时间 |
| latest_iteration | Integer | 最新迭代号 |
| creator_id | UUID | 创建者 |
| created_at | DateTime | 创建时间 |
| deleted_at | DateTime | 软删除 |

### 4.3 configuration_item_iterations（迭代）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID PK | 子构型项 `parent_iteration_id`、关联零部件 `iteration_id` 指向此处 |
| revision_id | UUID FK → revisions.id | 所属版本 |
| iteration | Integer | 迭代号 |
| check_in_note | Text | 签入说明 |
| version_name | String(255) | 迭代时名称 |
| document_links | JSONB | 关联图文档（**版本级**，始终展示当前迭代） |
| created_at | DateTime | 创建时间 |

### 4.4 子构型项（configuration_item_children）

> **绑定层级：迭代级**。`parent_iteration_id` 指向父构型项的迭代。签出时复制到新迭代，迭代历史查看时跟随变化。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID PK | 主键 |
| parent_iteration_id | UUID FK → iterations.id | **父迭代**（主绑定） |
| child_revision_id | UUID FK → revisions.id | 子构型项版本 |
| is_required | Boolean | 是否必选 |
| quantity | Integer | 用量 |
| sort_order | Integer | 排序 |

### 4.5 关联零部件（configuration_item_parts）

> **绑定层级：版本级**。`iteration_id` 指向所属迭代，但前端始终展示当前最新迭代的关联零部件，不随迭代历史变化。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID PK | 主键 |
| iteration_id | UUID FK → iterations.id | 所属迭代 |
| part_type | String(16) | 类型：part / assembly |
| part_id | UUID → part_masters.id | 零部件 Master ID |
| is_required | Boolean | 是否必选 |
| quantity | Integer | 用量 |
| sort_order | Integer | 排序 |

### 4.6 关联图文档

> **绑定层级：版本级**。存储在 `configuration_item_iterations.document_links` JSONB 列，签出时复制到新迭代。前端始终展示当前最新迭代的图文档，不随迭代历史变化。

### 4.7 自定义字段

> **绑定层级：版本级**。`entity_id = configuration_item_revisions.id`。内部支持迭代快照（`iteration_id` 列），签出时复制，撤销签出时清理，但 API 读写按版本级操作，不区分迭代。

**自定义字段生命周期**：
- **签出**：复制上一迭代的自定义字段到新迭代（带 iteration_id 快照）
- **撤销签出**：删除该迭代的自定义字段记录
- **升版**：**不复制**自定义字段到新版本（与零部件一致）

## 五、自定义字段存储

### 5.1 custom_field_definitions（字段定义）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID PK | 主键 |
| name | String(128) | 字段显示名 |
| field_key | String(64) | 字段唯一键 |
| field_type | String(32) | 类型：text / number / select / multiselect |
| options | JSONB | 选项列表（select/multiselect 专用） |
| is_required | Boolean | 是否必填 |
| applies_to | JSONB | 适用实体类型数组：["component", "configuration_item", "document"] |
| sort_order | Integer | 排序 |

### 5.2 custom_field_values（字段值）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID PK | 主键 |
| field_id | UUID FK → definitions.id | 字段定义 |
| entity_type | String(32) | 实体类型：component / document / configuration_item |
| entity_id | UUID | **指向 revision_id**（版本级绑定） |
| value_text | Text | 文本值（text/select） |
| value_number | Numeric(12,4) | 数字值（number） |
| value_json | JSONB | 多选值（multiselect） |
| iteration_id | UUID, 可空 | 迭代快照 ID（签出复制、撤销清理，API 层面不使用） |

### 5.3 绑定对照

| entity_type | entity_id 指向 | iteration_id 使用 | API 层级 |
|-------------|---------------|------------------|---------|
| `component` | part_revisions.id | 签出复制、撤销/删除清理 | **版本级** |
| `document` | document_revisions.id | 签出复制、撤销/删除清理、升版迁移 | **版本级** |
| `configuration_item` | configuration_item_revisions.id | 签出复制、撤销清理 | **版本级** |

## 六、版本号序列

24进制，不含 I 和 O（易与 1 和 0 混淆）：

```
A → B → C → ... → H → J → K → ... → N → P → ... → Z
→ AA → AB → ... → AZ → BA → ... → ZZ → AAA → ...
```
