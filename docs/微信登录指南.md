# 微信登录指南

> 适用版本：v1.6.1+
> 适用场景：PC 浏览器扫码登录（微信开放平台「网站应用」），以及在「系统设置」中绑定/解绑微信身份。

本文档说明 myPDM 微信登录的能力、前置条件、配置步骤、使用方式与常见问题。

---

## 1. 功能概述

- **扫码登录**：登录页底部出现「微信登录」按钮，点击后跳转微信扫码授权页，扫码确认后自动登录系统。
- **自动建号**：首次通过微信登录的用户会自动创建账号，角色为 `未验证`，无任何操作权限，需等待管理员在「用户管理 → 待审批」中分配角色后才能正常使用业务功能。
- **账号绑定**：已拥有系统账号的用户，可在「系统设置 → 微信绑定」中将账号与微信身份绑定，此后扫码登录将直接进入当前账号。
- **解绑**：在「系统设置 → 微信绑定」页面可解除绑定，解绑后可重新绑定到其他账号。
- **多入口隔离**：当前仅接入「微信登录」单一入口（`provider=wechat`）。若后续同时接入公众号网页授权，可按 `(provider, union_id)` 隔离模式扩展为 `wechat` / `wechat_gzh` 双入口。

> 微信登录与既有的飞书登录相互独立、并存运行，互不影响。未配置微信应用时，登录页不显示微信按钮。

## 2. 前置条件

| 条件 | 说明 |
| --- | --- |
| 微信开放平台账号 | 需注册「微信开放平台」(open.weixin.qq.com) 账号 |
| 网站应用 | 在开放平台创建**网站应用**，获取 `AppID` / `AppSecret` |
| 企业认证 | 网站应用需通过企业认证（300 元/年），否则无法使用扫码登录 |
| 已备案域名 | 回调地址域名需已完成 ICP 备案 |
| 授权回调域 | 在网站应用后台配置「授权回调域」，值为部署域名（不含协议与端口），例如 `your-domain:8080` |
| unionid（可选） | 若希望跨应用统一身份，需将网站应用绑定到同一开放平台账号并开通 unionid；未开通时系统自动回退使用 `openid` |

> 注意：微信登录依赖公网可达的回调地址。内网/局域网部署需确保回调域名能从微信服务器访问到。

## 3. 配置步骤

### 3.1 配置环境变量

在 `.env` 中增加以下变量（`.env` 不进版本库，仅本地/部署机生效）：

```dotenv
# 微信开放平台网站应用
WECHAT_APP_ID=你的网站应用AppID
WECHAT_APP_SECRET=你的网站应用AppSecret
# 回调基础地址，需与开放平台「授权回调域」一致；默认复用 FEISHU_REDIRECT_BASE
WECHAT_REDIRECT_BASE=https://你的访问域名:8080
```

完整回调地址为：`{WECHAT_REDIRECT_BASE}/api/auth/wechat/callback`

> `docker-compose.yml` 后端服务已透传 `WECHAT_APP_ID` / `WECHAT_APP_SECRET` / `WECHAT_REDIRECT_BASE`，无需修改编排文件。

### 3.2 部署 / 重启

```powershell
# 重新构建前端（如改动过前端）
cd frontend; npm run build

# 重启后端以加载新环境变量与新路由
docker compose up -d backend
```

### 3.3 验证

```powershell
curl.exe -sk https://你的访问域名:8080/api/auth/wechat/config
# 已配置且正确时返回：{"providers":[{"key":"wechat","name":"微信登录","app_id":"..."}]}
# 未配置时返回：{"providers":[]}（此时登录页不显示微信按钮）
```

## 4. 后端实现说明

| 模块 | 文件 | 职责 |
| --- | --- | --- |
| 客户端 | `backend/app/wechat_client.py` | 构造扫码授权 URL、授权码换 token、拉取用户信息 |
| 路由 | `backend/app/routers/wechat.py` | `config` / `authorize` / `callback` / `bind-intent` / `bindings` / `bindings/{provider}` |
| 数据访问 | `backend/app/crud.py` | `get/find_or_create/bind/unbind_wechat` 等函数 |
| 模型 | `backend/app/models.py` | `UserWechatBinding` 绑定表 |
| 注册 | `backend/app/main.py` | 注册 `wechat_router`（`/api/auth/wechat`） |

### 4.1 身份唯一键

微信返回 `unionid`（跨应用一致）与 `openid`（单应用内唯一）。

- 优先使用 `unionid` 作为绑定唯一键；
- 若应用未开通 unionid，则回退使用 `openid`；
- 绑定表 `user_wechat_bindings` 以 `UniqueConstraint(provider, union_id)` 保证单入口仅绑定一个账号。

### 4.2 自动建号与角色

`find_or_create_wechat_user` 在 `(provider, union_id)` 无绑定时：

1. 创建系统用户，`real_name` 取微信昵称 `nickname`，角色 `unverified`，状态 `active`；
2. 生成随机密码（用户不可见，仅用于账号存在性）；
3. 写入 `user_wechat_bindings` 绑定记录。

### 4.3 绑定 / 解绑语义（与飞书一致）

- 微信身份已绑定到 `guest`（访客）账号：绑定到新账号时自动停用旧访客账号；
- 微信身份已绑定到正式账号（非访客）：绑定被拒绝，需先由原账号解绑；
- 通过微信首次注册的「未验证」用户被管理员审批后，其微信身份已自动绑定，无需再次手动绑定。

### 4.4 登录态

回调成功后签发 JWT（`access_token` + `refresh_token`），与账号密码、飞书登录共用同一套令牌体系，前端 `WechatCallback` 页面写入令牌后跳转首页。

## 6. 与飞书登录的差异

| 维度 | 飞书 | 微信 |
| --- | --- | --- |
| 入口形态 | 浏览器授权 + 客户端内 JSSDK 免登（双通道） | 仅 PC 扫码（单通道） |
| 身份键 | `union_id` | `unionid`（回退 `openid`） |
| 用户姓名 | `name`（真实姓名） | `nickname`（昵称，非真实姓名） |
| 客户端自动触发 | 飞书客户端内自动发起免登 | 无（需手动点击按钮扫码） |
| 资质 | 飞书开放平台应用 | 微信开放平台网站应用 + 企业认证 |

## 7. 常见问题

**Q1：登录页没有「微信登录」按钮？**
- 检查 `.env` 是否配置了 `WECHAT_APP_ID` / `WECHAT_APP_SECRET`；
- 确认后端已重启（`docker compose up -d backend`）；
- `GET /api/auth/wechat/config` 返回 `{"providers":[]}` 表示未配置。

**Q2：扫码后提示「redirect_uri 参数错误」？**
- 微信开放平台「授权回调域」必须与 `WECHAT_REDIRECT_BASE` 的域名一致（不含 `https://` 与端口的部分，但本系统端口在路径之外，需确保开放平台填写的回调域能命中部署地址）；
- 回调域不能带协议、路径、query；仅域名。

**Q3：不同微信用户登录却是同一账号？**
- 未开通 unionid 时以 `openid` 为键，单网站应用内正常；若多个应用共用需注意 unionid 一致性。

**Q4：绑定提示「该微信身份已绑定其他账号」？**
- 该微信身份已绑定到正式账号，需先由原账号在「微信绑定」中解绑后再绑定。

**Q5：内网部署无法回调？**
- 微信要求回调地址公网可达，内网/局域网需通过反向代理或公网隧道暴露 `WECHAT_REDIRECT_BASE` 对应地址。
