# 移动端网页响应式适配设计

日期：2026-07-25
分支：V3.0
状态：设计定稿，待实施

## 1. 背景与目标

现有前端为纯桌面网页（React + Vite + TypeScript + Tailwind + react-router + zustand）。
需要让同一个 Web 应用在手机浏览器上可用。

**目标**
- 一套代码做响应式改造，不新建工程、不新建移动专用路由。
- 桌面端零回归——所有改动以"移动优先叠加"方式书写，不改变现有 `md:`/`lg:` 语义。
- 权限继续由登录角色决定，**不做移动端专属只读限制**（原设想的"移动只查看"已放弃）。

**首期范围**
- 覆盖高频查询模块：仪表盘、看板、零部件管理、图文档管理、构型管理、变更管理、库存管理、通知中心、系统设置。
- **延后**：Three.js STEP/3D 查看器（STPViewer）、CAD 工作台（CADWorkspace）、OfficeReader 等重模块。手机上先给"请用电脑打开"占位提示，不做适配。

## 2. 断点约定

- 以 Tailwind 默认 `md`（768px）为界：`< md` 判定为移动端，`≥ md` 保持现桌面布局。
- 所有新增移动样式一律写成：基础类 = 手机，`md:原类` = 桌面（移动优先叠加）。
- 不删除或改写现有的 `md:`/`lg:`/`xl:` 前缀语义，避免桌面回归。
- `viewport` meta 已存在于 `index.html`，无需改动。

## 3. 导航改造（`components/Layout.tsx` 一处）

- `< md`：侧边栏 `<aside>` 改为 `hidden md:flex`，隐藏。
- `< md`：顶部新增一条 AppBar（约 48px 高）：左汉堡图标 + 中间当前页标题（来自 `usePageHeader` 或路由）+ 右侧 `NotificationBell`。
- 点汉堡从左滑出 Drawer 抽屉：内部**直接复用现有 `visibleNavItems`**（含角色过滤与分隔符渲染逻辑），保证菜单与桌面完全一致。点遮罩层或选中菜单项后关闭。
- Drawer 底部保留现有的用户信息 / 登出 / 同步等操作（复用侧边栏底部区块）。
- `FloatingAssistant` 在 `< md` 下缩小并避让底部/抽屉，不遮挡内容。
- 新增轻量 hook `hooks/useIsMobile.ts`：基于 `window.matchMedia('(max-width: 767px)')`，返回布尔并监听变化，供少数需按端切换渲染的组件使用。

## 4. 表格适配——全部卡片化

**策略：所有表格在 `< md` 时渲染为卡片/列表形式，`≥ md` 保持原 `<table>`。**

- 抽取共享组件 `components/ResponsiveTable.tsx`（或 `CardList`）：
  - 接收列定义（复用现有表头/字段）与行数据。
  - `≥ md`：渲染标准 `<table>`（尽量与现有结构一致，减少视觉差异）。
  - `< md`：每行渲染为一张卡片——主标题（如编号/名称）+ 2–3 行关键字段（label + value）+ 状态徽标 + 行操作（折叠为"操作"下拉或图标）。
- 覆盖两类表格：
  - **核心列表页表格**（零部件、图文档、构型、库存、变更、看板等）→ 卡片视图。
  - **详情内嵌小表格**（属性、附件、版本记录等）→ "标签 + 值"的卡片/列表形式。
- 全站约 58 处 `<table>` 逐步迁移到该组件；按第 7 节顺序增量推进，不必一次做完。未迁移的表格在过渡期以 `overflow-x-auto` 兜底避免撑破布局。

## 5. 详情弹窗（`components/Modal.tsx` 一处）

- 大部分详情走共享 `Modal` 组件（`PartDetailModal`、`DocumentDetailModal` 等）。
- `< md`：Modal 变全屏——`inset-0`、去圆角、顶部固定标题+关闭条、内容区独立滚动。
- `≥ md`：保持现有居中卡片与 `widthMap` 尺寸。
- 改一处覆盖大部分详情场景。

## 6. 触控与细节

- 可点区域 ≥ 40px（`min-h`/`py` 补足）。
- 页面工具栏：`< md` 时按钮折叠为图标或"操作"下拉；搜索/筛选栏堆叠为整行、单列。
- 长编号/长文本：`break-all` 或省略号处理，避免撑破卡片。
- 表单在 `< md` 下单列堆叠（保留编辑能力）。

## 7. 实施顺序（增量，可随时停）

1. **地基**：AppBar + Drawer（`Layout.tsx`）、`useIsMobile` hook、全屏 `Modal`。完成后全站在手机上可进入、可看详情。
2. **共享组件**：实现 `ResponsiveTable`，先落地零部件 → 图文档 → 构型三个高频页。
3. **铺开**：变更 / 库存 / 看板 / 仪表盘。
4. **收尾**：其余表格迁移或 `overflow-x-auto` 兜底；3D/CAD/OfficeReader 加"请用电脑打开"占位提示。

## 8. 验证

- Chrome DevTools 移动仿真（375px / 390px）+ 真机抽测。
- 桌面端 `≥ md` 逐页对比，确认无回归。
- `npm run build` 通过；关键页 `npm run test` 绿。

## 9. 明确不做（YAGNI）

- 不新建移动专用工程 / 路由 / PWA。
- 不做移动端专属只读权限。
- 首期不适配 3D 查看器、CAD 工作台、OfficeReader。
- 不引入新的 UI 组件库；沿用现有 Tailwind + primary 配色 + 共享 Modal/表格约定。
