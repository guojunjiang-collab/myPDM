# 任务编辑界面 UI 改造设计

> 日期: 2026-07-08 | 版本: v1.0

## 一、背景

当前 `TaskEditModal` 是一个纯 TAB 分页的弹窗，所有表单字段和功能都隐藏在 TAB 内部。用户编辑任务核心信息时需要手动切换到对应 TAB，操作不够直观。

参考零部件详情界面（`PartDetailModal`）的上下分栏布局，将任务编辑界面改造为：**上方核心信息区始终可见 + 下方 TAB 分页内容区**，提升操作效率。

## 二、目标

- 保持 Modal 弹窗形式不变
- 采用上下分栏布局（核心信息固定 + TAB 可切换）
- 复用以 InfoItem 卡片为代表的现有视觉风格
- 不改变现有功能逻辑（保存、状态流转、依赖、关联、评论等）

## 三、整体布局

```
Modal (max-w-4xl)
└── div.h-[65vh].flex.flex-col
    ├── 【上】核心信息区 (shrink-0)
    │   └── 6列栅格 InfoItem 卡片：编号、名称、类型、状态、优先级
    ├── 【下】TAB 区 (flex-1 min-h-0)
    │   ├── TAB 导航栏 (shrink-0)
    │   └── 内容区 (overflow-y-auto flex-1)
    └── 底部操作栏 (shrink-0)：状态操作按钮(左) ... 取消(右) 保存(右)
```

关键 CSS 类与 PartDetailModal 保持一致。

## 四、核心信息区

始终可见，shrink-0 不随 TAB 切换隐藏。

### 4.1 字段

| 字段   | 类型     | 说明                                       |
| ------ | -------- | ------------------------------------------ |
| 编号   | 只读文本 | 自动生成的任务编号（如 TASK-001）           |
| 名称   | 输入框   | inline 编辑，必填                          |
| 类型   | 下拉选择 | 任务 / 里程碑 / 评审                       |
| 状态   | 彩色标签 | 未开始(蓝) / 进行中(绿) / 挂起(橙) / 已完成(灰) |
| 优先级 | 下拉选择 | 高 / 中 / 低                               |

### 4.2 样式

复用 `InfoItem` 卡片组件（`bg-gray-50 rounded-lg px-3 py-2 border border-gray-100`），5 个卡片使用 6 列栅格 `grid grid-cols-6 gap-3`。

名称字段占用 2 列（`col-span-2`），编号/类型/状态/优先级各占 1 列，总计 1+2+1+1+1 = 6 列。

### 4.3 状态操作按钮

根据当前状态动态显示，放置在底部操作栏左侧，与现有实现一致。

## 五、TAB 分页

4 个 TAB：基本信息、关联对象、评论、操作日志

### 5.1 TAB1：基本信息

分区卡片布局，包含四个子区域：

**负责人**
- 用户选择下拉框

**计划周期（四列栅格）**
- `grid grid-cols-4 gap-3`，InfoItem 卡片样式
- 计划开始（可编辑日期选择器）
- 计划完成（可编辑日期选择器）
- 实际开始（只读灰色）
- 实际完成（只读灰色）

**描述**
- 多行文本框 `textarea`，`min-h-[80px]`

**任务依赖**
- 前置任务表格 + 后置任务表格
- 列：依赖任务名称、依赖类型(FS/SS/FF/SF)、延迟天数、状态（正常/违规）、删除按钮
- 现有逻辑不变，仅样式适配

### 5.2 TAB2：关联对象

- 表格列表：类型（彩色徽章）、编号（可点击查看详情）、名称、版本、状态、取消关联按钮
- 底部"添加关联"按钮，触发 `AssemblyPartPicker` / `DocumentPicker` / `ECPicker` 等选择弹窗
- 现有逻辑不变

### 5.3 TAB3：评论

- 评论列表（用户头像→用户名→时间→内容→删除按钮）
- 评论输入框 + 发送按钮
- 现有逻辑不变

### 5.4 TAB4：操作日志

- 审计日志表格：时间、操作人、操作、详情
- 现有逻辑不变（调用操作日志 API）

## 六、底部操作栏

- 布局：`flex justify-between items-center pt-3 border-t`
- 左侧：状态操作按钮（与现有逻辑一致）
  - 未开始 → ▶ 开始任务
  - 进行中 → ⏸ 暂停任务 / ✓ 完成任务
  - 挂起 → ▶ 恢复任务
  - 已完成 → ↩ 退回
- 右侧：`flex gap-2`，取消按钮 + 保存按钮

## 七、影响的文件

| 文件 | 变更说明 |
|------|---------|
| `frontend/src/pages/Project/TaskEditModal.tsx` | 主要改造文件，重写布局结构 |
| `frontend/src/components/Modal.tsx` | 无变更（复用现有） |
| 其他组件 | 无变更（复用现有选择器、表格等） |

## 八、验收标准

1. Modal 打开后，核心信息区（编号/名称/类型/状态/优先级）始终可见
2. 切换 TAB 时核心信息区不随内容区滚动隐藏
3. 日期四列栅格布局正常，实际日期只读
4. 状态操作按钮根据任务状态正确显示/隐藏
5. 保存功能正常（所有 TAB 的修改均正确提交）
6. 组件高度固定（65vh），内容溢出时可滚动
7. 视觉风格与零部件详情界面一致
