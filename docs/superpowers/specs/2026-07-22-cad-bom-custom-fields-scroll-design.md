# CAD BOM 匹配表格自定义字段滚动区设计

> 状态：已确认 | 日期：2026-07-22

## 问题

BOM 匹配表格中的 PDM 自定义字段列从字段定义动态加载，当自定义字段较多时表格过宽，无法在 CAD 入口弹窗内完整显示。

## 方案

将单一 `<table>` 拆分为两个并排表格，自定义字段列放入独立水平滚动区。

### 布局

```
┌──────────────────────────────────────────────────────────────┐
│  固定列表格 (shrink-0)     │  自定义字段滚动区 (flex-1, max-w-[50%]) │
│                            │  ← 水平滚动 →                     │
│ 层级│件号│用量│版本│术语│..│操作 │  规格型号 │ 重量 │ 存货类别 │ ... │
│  0  │ABC │ 2  │ A  │xxx │..│签出 │    M8    │ 2.5  │  原料   │     │
│                            │                                   │
│  ← 两表同步垂直滚动（同一父容器） →                              │
└──────────────────────────────────────────────────────────────┘
```

### 固定列清单（左表）

层级、件号、用量、版本、术语/中文名称、CAD附件、生产附件、PDM匹配、匹配状态、签出状态、操作

### 滚动列清单（右表）

所有 PDM 自定义字段（从 `customFieldsApi.listDefinitions()` 筛选 component/part/assembly 适用）

### 实现要点

1. **双表结构**：外层 `flex` 容器，左表 `shrink-0`，右表放 `overflow-x-auto` 容器，右容器 `flex-1` + `max-w-[50%]`
2. **垂直同步**：两表放在同一 `overflow-y-auto` 父容器，天然同步滚动
3. **行高对齐**：统一 `h-8`，确保左右表行一一对应
4. **表头处理**：自定义字段区表头跟随水平滚动，固定列表头 sticky 保持可见

### 改动范围

仅修改 `frontend/src/components/CADWorkspace/CADBOMMatchTable.tsx` 表格渲染 JSX（~490-690 行），不涉及数据逻辑。

### 约束

- 弹窗宽度 `max`（约 1280px），高度 `85vh`
- 不引入新依赖
- 保持现有编辑、上传、推送等交互功能不变
